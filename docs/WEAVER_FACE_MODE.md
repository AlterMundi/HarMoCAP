# Facial contours in the Weaver laboratory

The maintained [Harmonic Weaver](https://github.com/AlterMundi/harmonic-weaver) laboratory provides a **Rostro** entry beside the HarMoCAP body view. Install/build its ordinary laboratory UI and use its existing launch command; open `?mode=face` or choose **Rostro**. The pinned dense-face model and WASM are shipped in that UI build.

The face view uses a camera connected to the viewing browser's computer, explicit consent, one face, a personal resting reference and contour-driven browser audio. It can enrich an aligned harmonic series or displace upper partials from measured mouth/brow/eye changes. It does not infer an emotion label or segment skin wrinkles. This is an authored exploratory mapping.

Native HarMoCAP continues to produce its existing body keypoints and stream; no new dense-face fields or OSC contract are claimed. If body capture already holds the same camera, explicitly stop it in Weaver's **Fuentes** before connecting the browser face source. Return with **Cuerpo · HarMoCAP**. Switching views does not rewrite the accepted body voices/preset or implicitly stop the native runtime.

See Weaver's [contour instrument contract](https://github.com/AlterMundi/harmonic-weaver/blob/main/docs/laboratory/face/CONTOUR_INSTRUMENT.md) and [next human experiment](https://github.com/AlterMundi/harmonic-weaver/blob/main/docs/laboratory/face/HUMAN_EXPERIMENT.md). Camera access needs localhost or HTTPS and the actual browser permission; physical tracking/listening acceptance is separate from software tests. No public camera hosting service is implied.
